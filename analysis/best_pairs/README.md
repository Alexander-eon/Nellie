## Что в файлах

Каждый .npz содержит:
- `actions_a` — действия агента A (управляет CPU)
- `actions_b` — действия агента B (управляет GPU)
- `cpu` — реальный cpu_load
- `gpu` — реальный gpu_load
- `target_cpu` — цель для CPU (знает только B)
- `target_gpu` — цель для GPU (знает только A)

## Что анализировать

1. Как A кодирует target_gpu в действиях на CPU?
2. Как B читает target_gpu из cpu_load?
3. Как B кодирует target_cpu в действиях на GPU?
4. Как A читает target_cpu из gpu_load?
5. Есть ли устойчивые паттерны (прото-слова)?
